# 末日回响 · Echoes of the Undead

一个本地运行的 **AI 文字生存游戏**：丧尸爆发前夜，你从第 1 天清晨开始求生。AI 负责叙事，本地负责数值、时间、成功率、伤情、地图等规则。

> 写实、压抑、资源稀缺。你只是普通人，不是天降救世主。

## 特点

- **AI 叙事**：由本机 Claude Code CLI 生成每一回合的剧情、对话与选项，写实压抑、资源稀缺。
- **本地规则**：24 小时时间系统、昼夜光照、六档行动判定、身体部位伤情、7×7 地图、联系人、图鉴、存档。
- **自定义行动**：输入行动 → AI 评估耗时与成功率 → 确认后执行；成功率与掷骰决定本回合结果。
- **角色与联系人**：姓名、性别、性格、外观体貌、兴趣嗜好；联系人带好感度（敌对/戒备/陌生/友善/亲密）。
- **货币与资源**：官方货币在爆发前可用、爆发后失效；角色有负重与携带量上限（背包/布袋提升携带量，体质提升负重）。
- **载具**：车辆状态、燃料、载货量与载重，可帮玩家搬运更多物资。
- **建筑结构**：记录已解锁建筑的整体状态、房间与出入口，随时间和玩家互动变化。
- **零依赖**：服务端只用 Node.js，不安装任何 npm 包；AI 引擎调用本机 `claude` CLI。

## 快速开始

1. 安装 [Node.js](https://nodejs.org/) 与 [Claude Code CLI](https://docs.anthropic.com/claude-code/)（`claude` 需已登录可用）。
2. 双击 `启动聊天.bat`（或在本目录运行 `node server.js`）。
3. 浏览器打开 `http://127.0.0.1:3456`。

## 目录结构

| 文件 | 作用 |
|---|---|
| `丧尸生存.html` | 全部界面与前端逻辑（单文件，含开局创建、时间、成功率、健康、地图、图鉴、存档等） |
| `server.js` | 零依赖本地服务：静态托管 + `/api/game`（叙事）、`/api/origin`（出身生成）、`/api/analyze`（行动评估） |
| `叙事设定.txt` | 主叙事提示词模板（世界观、规则、输出 JSON 格式） |
| `出身生成.txt` | 自定义职业出身生成提示词 |
| `行动分析.txt` | 自定义行动的 AI 评估提示词（耗时、难度、属性、技能、装备、成功率） |
| `据点参考.txt` | 建筑/据点结构参考（状态、出入口、房间），供建筑系统设计参考 |
| `启动聊天.bat` | 启动服务并打开浏览器 |
| `会话摘要.md` | 开发记录与注意事项 |

## 玩法

- 开局自定义姓名、性别、性格、出身（8 种内置 + 自定义职业）与三档难度。
- 从第 1 天清晨开始，每个行动消耗时间；爆发日按难度随机到来。
- 自定义行动先由 AI 评估耗时与成功率，确认后才执行；内置选项、物品快捷使用、地图移动为本地即时结算。
- 顶部 13 个系统标签：健康 / 物品栏 / 地图 / 联系人 / 属性 / 载具 / 建筑 / 世界 / 场景 / 事件 / 日志 / 图鉴 / 存档。

## 说明

- 游戏数据保存在浏览器 localStorage，并可从「存档」页导出到 `存档/` 目录。
- AI 引擎默认通过 `claude -p` 调用本机 CLI。若想更快，可在「设置」把 CLI 模型设为 `sonnet` 或 `haiku`，或设置环境变量 `NARRATE_MODEL` / `ORIGIN_MODEL` / `ANALYZE_MODEL`。
