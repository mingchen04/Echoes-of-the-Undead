# 末日回响 · Echoes of the Undead

一个本地运行的 **AI 文字生存游戏**：丧尸爆发前夜，你从第 1 天清晨开始求生。AI 负责叙事，本地负责数值、时间、成功率、伤情、地图、资源等规则。

> 写实、压抑、资源稀缺。你只是普通人，不是天降救世主。

## 特点

- **AI 叙事**：由本机 Claude Code CLI 生成每一回合的剧情、对话与选项，写实压抑、资源稀缺。
- **本地规则**：24 小时时间系统、昼夜光照、六档行动判定（先判定骰定成败，再命运骰定档次：≤10 大失败档、≥90 大成功档）、身体部位伤情、7×7 地图、联系人、图鉴、存档。
- **自定义行动**：输入行动 → AI 评估耗时与成功率 → 确认后执行；成功率决定底判成败，命运骰决定大成功/大失败档位。
- **角色**：姓名、性别、性格、外观体貌、兴趣嗜好。外观与癖好在**选出身时**设定，之后只随剧情与行动变化。
- **联系人**：好感度（敌对 / 戒备 / 陌生 / 友善 / 亲密）、体貌、嗜好、电话或无线电联系方式。
- **货币**：官方货币在爆发前可用，爆发后失效，只能以物易物。
- **负重与携带量**：角色有负重上限（体质决定）与携带量上限（背包/布袋增加）；携带量是硬上限，装不下会被拒收；负重过高会降低行动成功率。
- **载具**：车辆状态、燃料、载货量与载重，可帮玩家搬运更多物资。
- **建筑结构**：记录已解锁建筑的整体状态、房间与出入口，随时间和玩家互动变化。
- **开局有熟人**：每个出身自带一笔钱、一个自己的家（地图上的已知地点）和 1~2 个认识的人的联系方式；部分出身还自带载具（快递员的电动车、消防员的消防车、修车工的面包车），起始场景会自动登记为当前建筑。
- **零依赖**：服务端只用 Node.js，不安装任何 npm 包；AI 引擎调用本机 `claude` CLI。

## 快速开始

1. 安装 [Node.js](https://nodejs.org/) 与 [Claude Code CLI](https://docs.anthropic.com/claude-code/)（`claude` 需已登录可用）。
2. 双击 `启动聊天.bat`（或在本目录运行 `node server.js`）。
3. 浏览器打开 `http://127.0.0.1:3456`。

## 目录结构

| 文件 | 作用 |
|---|---|
| `丧尸生存.html` | 全部界面与前端逻辑（单文件，含开局创建、时间、成功率、健康、地图、联系人、载具、建筑、图鉴、存档等） |
| `server.js` | 零依赖本地服务：静态托管 + `/api/game`（叙事）、`/api/origin`（出身生成）、`/api/analyze`（行动评估） |
| `叙事设定.txt` | 主叙事提示词模板（世界观、规则、输出 JSON 格式） |

| `行动分析.txt` | 自定义行动的 AI 评估提示词（耗时、难度、属性、技能、装备、成功率） |
| `据点参考.txt` | 建筑/据点结构化参考（状态、出入口、房间），供建筑系统与提示词设计参考 |

| `会话摘要.md` | 开发记录与注意事项 |

## 玩法

- 开局自定义姓名、性别、性格、外观体貌、癖好、出身（8 种内置 + 自定义职业）与三档难度。
- 从第 1 天清晨开始，每个行动消耗时间；爆发日按难度随机到来。
- 自定义行动先由 AI 评估耗时与成功率，确认后才执行；内置选项、物品快捷使用、地图移动为本地即时结算。
- 顶部 13 个系统标签：健康 / 物品栏 / 地图 / 联系人 / 属性 / 载具 / 建筑 / 世界 / 场景 / 事件 / 日志 / 图鉴 / 存档。

## 系统说明

### 角色与出身

- 8 种内置出身：快递员、急诊护士、消防员、便利店店员、户外社学生、退伍军人、修车工、自媒体主播；第 9 项可输入职业描述由 AI 生成。
- 外观体貌与癖好在创建页填写；进入游戏后「编辑档案」只读展示，不能手动改，只能随行动变化（受伤留疤、换装、养成新习惯等由 AI 写入）。

### 联系人

- 每个联系人记录：关系、最后已知地点、最近联系时间、联系方式（电话 / 无线电 / 当面 / 未知）、好感度、体貌、嗜好。
- 开局即带有对应出身的熟人（如护士的护士长和妈妈、消防员的队友和妻子）。

### 货币

- 官方货币（¥）只在爆发前可用；爆发后失效，只能以物易物、搜刮或人情交换。
- 属性面板显示货币余额与「可用 / 已失效」状态。

### 负重与携带量

- 负重上限 = 15 + 体质 × 0.5（kg）；携带量上限 = 12 + 每件背包/布袋/腰包/挎包 +4。
- 携带量是硬上限：拾取超出会被拒收或截断，并给出提示。
- 负重 >70% / >85% / 超过上限时，分别扣减行动成功率，警告条会提示。

### 载具

- 记录载具名称、类型、状态、燃料、载货量、载重与货物清单；可帮助携带更多物资。

### 建筑结构

- 记录已解锁建筑的整体状态、房间（名称 / 状态 / 说明）与出入口（名称 / 状态 / 说明）。
- 房间与出入口状态会随时间和玩家互动变化（清理、封堵、破坏、囤物资等）。

## 存档与导出

- 游戏数据保存在浏览器 localStorage，可从「存档」页导出 13 个文本文件 + `完整存档.json`：
  角色状态、伤情记录、背包物品、场景与地图、地点坐标、联系人、载具、建筑、世界概况、收集日志、图鉴、丧尸图鉴、对话记录。

## 说明

- AI 引擎默认通过 `claude -p` 调用本机 CLI。若想更快，可在「设置」把 CLI 模型设为 `sonnet` 或 `haiku`，或设置环境变量 `NARRATE_MODEL` / `ORIGIN_MODEL` / `ANALYZE_MODEL`。
- 各接口默认模型：叙事沿用 CLI 默认，出身生成 `sonnet`，行动分析 `haiku`（均可在设置或环境变量中覆盖）。
